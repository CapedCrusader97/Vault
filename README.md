This Personal Finance & Portfolio Tracker is a comprehensive web-based application designed to help individuals centralize their financial life. 

In an era of fragmented subscriptions and multiple payment dates, this platform acts as a single source of truth for a user’s liquidity.

The system allows users to securely log in and manage their financial obligations, including one-time payments, recurring monthly bills, and active subscriptions. By leveraging a Django backend, the platform ensures data integrity and security, while the frontend provides a clean, intuitive dashboard for visualizing spending habits and upcoming liabilities
